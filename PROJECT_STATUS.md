# Статус проекта — Hidromarket 25 SRL, сайт

## Контекст
Сайт для компании **Hidromarket 25 SRL** (Молдова, Кишинёв), по образцу структуры сайта
поставщика **Hipomak** (hipomak.com, Турция, гидравлическое оборудование).
Hidromarket 25 SRL — импортёр/дистрибьютор оборудования Hipomak, это нужно отразить на сайте
как партнёрство (не выдавать себя за Hipomak). Также с 2026-07-29 сайт включает гидравлические
рукава производителя **SEL Hortumları (Danfoss)** (selhoses.com, Турция) — второй партнёр/
поставщик, отражён отдельным бейджем в шапке и футере (не путать с историей "партнёр с 1988" —
это относится только к Hipomak).

## Технический стек
- Node.js + Express + EJS (шаблоны)
- База данных: встроенный `node:sqlite` (НЕ better-sqlite3 — на компьютере нет Python/build tools
  для нативной сборки, поэтому используется штатный модуль Node 22.5+)
- Файлы проекта: `C:\Users\Asus.DESKTOP-ESK6K1M\Desktop\hidromarket25-site`
- Запуск: `npm run dev` (или через Launch preview: конфигурация "hidromarket25-site" в
  `.claude/launch.json`, порт 3000)
